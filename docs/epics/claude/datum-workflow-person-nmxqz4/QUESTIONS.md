### Q4: [Behavior] What should tier-up retry do when two tiers map to the same model id, or a tier's model id is missing?

[Answer]: (a) Yes: a missing `models.fast`, `models.balanced` or `models.deep` is a config error from `readRuntimeConfig`, `runtime_models_missing: <tier>`. Any other literal not in the map is `runtime_model_unknown: <id>` and the call fails by name. No fallback to the next defined tier.
