| SEC-001 | **medium** | skills/src/shared/plan-steps.ts | 53 | renumberDecisionSteps builds the shell command `git show HEAD:${epicDir}/lane-plan.json` by raw string interpolation of epicDir, with no quoting. That command string is later written verbatim into a bash heredoc and executed with `bash "$__f"` by batchScript() (skills/src/shared/batch.ts:79-112) — BatchStep.command is documented there as 'Shell text, run inside a { ... } group in the current shell'. Every other builder in this same file quotes epicDir before interpolating it: lanePlanCommand (line 34) wraps every `${epicDir}/...` argument in `q()` (backtick/dollar/quote-escaping), and skeletonBatchSteps (line 90) does the same. epicDir is `docs/epics/<branch>` (skills/src/datum-plan.ts:89, `ctx.epicDir`), and git branch names may contain shell metacharacters such as `$()`, backticks, and `;` (git ref-name rules only forbid space, ~^:?*[\ and a few others) — so an epic branch name chosen by whoever created it can inject arbitrary commands into the batch script the agent runs. This breaks the quoting discipline the file explicitly calls out elsewhere (see the review-finding comment on completionMarkerCommand about a quote 'breaking out' of an interpolated shell argument).
